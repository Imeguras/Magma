# Theory of Operation

The way Magma operates is relatively similar to NVIDIA's Deepstream, this is mostly to prevent having to learn from scratch an already niche tool inside a niche field. 
Magma works over gstreamer library and many of its patterns and inner workings are heavily based(sometimes even forced) on gstreamer patterns and paradigms, its heavily advised to read gstreamer documentation in order to understand how to operate with magma specially as many of the tools you'll be using are gstreamer ones.
